## Terms

- Decision payload: the effect block in a decision, usually adding/removing deposits.
- Deposit payload: the long-lived effect package in a deposit definition.
- Inline script: reusable script file called by multiple definitions.
- Candidate marker: temporary modifier/flag marking valid targets before final build/action.
